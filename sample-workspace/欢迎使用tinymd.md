## 快速上手

- 在欢迎页点击`打开文件夹，选择任意一个文件夹作为工作空间`
- `左侧边栏可在文件与大纲之间切换（侧栏右缘可拖拽调宽）`
- `双击文件打开，停止输入约 0.6 秒后自动保存`
- 输入 `/` *呼出命令菜单，快速插入各种块*

## *支持的语法*

### 列表

1. 无序列表，用 `-`  开头
2. 有序列表，用 `1.`  开头
3. 任务列表，用 `[ ]`  开头

- [x] 写下第一行文字
- [ ] 试一试斜杠命令
- [ ] 粘贴一张图片进来

### 表格

在表格内**右键**即可插入/删除行列、切换标题行。


| 快捷键        | 功能       | 但是发射点士大夫 |
| ---------- | -------- | -------- |
| `Ctrl + O` | 打*开文*件夹  |          |
| `Ctrl + N` | 新~~建文~~件 |          |
| `Ctrl + \` | 切换边栏     |          |
| `Ctrl + S` | 立即保存     |          |


### 图片

粘贴、拖入图片，会以原始二进制存入工作空间的 `assets/` 文件夹，文档里用相对路径引用，不转 base64。
